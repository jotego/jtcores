# 1B11142 Z80µP AUDIO board digest (MAME: zac1b11142_audio_device)

3 sheets, P82-020/M2, 17.5.1983. Connectors: CN2 (to I/O board: HS0..7 command,
SPK out, power, ACS/RESSOUND), CNA (to ROM module CN3: both 6802 buses — the
program ROMs for both audio CPUs live on the ROM module).

## Sheet 1/3 — melody CPU + 2× AY-3-8910

- 6802 at 4L ("melodycpu"), XTAL1 = 3.580MHz (QZ1, LS368-style 74S04 6L oscillator,
  R137/R138 470R, C68 1000p) -> E = 895kHz internal /4.
- Address decode: 6I LS156 (A13/A14/A15 + VMA via 6H) -> /CS2 (PIA), /CS4A, /CS5A
  (ROM selects to CNA/module), /CS0A /CS1A (more ROM selects, sheet1 top left CNA pins
  50/49/4/2). AR8/AR9 10K pullup packs on both buses.
- 5F 4040 ripple counter clocked by E(?): output 9 = CKGI (AY clock ~895kHz/... see
  below) and via 4F LS74 /2 -> CB1 (PIA cadence interrupt, MAME's timebase clock);
  MAME: timebase = XTAL/4/2? (zaccaria_a.cpp: 6802 E * ... ) — transcribe exact tap.
- 6821 PIA 4I ("melodypia"): D0..7, /CS2 select, A0/A1 = AB0/AB1(A2/A3? pins 24/22 = A2 A3 shown),
  IRQA/IRQB -> 6802 /IRQ (R37/R35/R36/R38 3K3 pullups). PA0..7 -> both AY data buses;
  PB0/PB1 = AY1 BC1/BDIR (pins 29/27), PB2/PB3 = AY2 BC1/BDIR. CA1 = CB1 timebase(?).
- AY-3-8910 #1 at 4H ("melodypsg1"): outputs A/B/C = ANAL4 / ANAL5 / ANAL6 (SH2).
  Port A bits: LEVEL (pin21), LEVELT (pin20), SW1 (pin13) — the tromba level +
  filter-select controls (MAME port A bits 0,3&4). CKGI clock, /RST from RST.
- AY-3-8910 #2 at 4G ("melodypsg2"): outputs A/B/C = ANAL1 / ANAL2 / ANAL3 (SH2).
  Port A = IOA0..IOA4 (SH2, analog switch controls), port B = IOB0..IOB7 (SH3,
  to speech board DAC path? IOB goes to SH3 = sheet 3: 2G LS374 comparison — actually
  IOB0..7 read/written on sheet 3 via CSCOM latches: inter-CPU comm port).
- RESSOUND (from I/O LS259) -> R135 4K7/R134 100K + C64 4.7µ + BC548 T8 + D2 ->
  stretched /RST to both audio CPUs (MAME ressound_w).

## Sheet 2/3 — analog channels and mixer

LM3900 quad norton opamps (5B, 5C ×2 packages) + 4016 analog switches (5D):
- ANAL1 (AY2 ch A) -> switchable filter (IOA4/IOA3 via 4016 5D routes) -> 5C 3900
  (R130 33K/R131 150K/R120 47K) => RULLANTE (snare); second stage 5C (R125 560K,
  R126 470K, R127 100K, R128 56K/680R, C61/C62) => CASSA (bass drum).
  (MAME: 8910 #0 ch A drum roll/bass drum selected by port A bits 3&4.)
- ANAL2 (AY2 ch B) -> 5B 3900 (R98 180K, R69 2K2, R99 47K, C52/C53) + 5C stage
  (R83 2K2, R85 120K, C45, R86 100K) => BASSO.
- ANAL3 (AY2 ch C) -> R72/R70 10K + 5D 4016 switch (C56 0.01µ filter option) ->
  straight out (jumper 1/2 pads) — MAME "straight out through optional filter".
- ANAL4 (AY1 ch A) -> R78 1K + C41... 5B 3900 (R79 47K, R107/R93 100K, C49 0.01)
  => PIANO.
- ANAL5 (AY1 ch B) -> T6 BC548 buffer + 3A LS74 (squarer?) + 4A LS14 + R110/R112/R95
  100K + 5B 3900 + 5D 4016 (R113 1M, C50 1000p) => TROMBA (trumpet, level via
  LEVELT/LEVEL transistor T7 BC548 divider P1 10K on sheet2 top-right: R114 4K7,
  R115 82K, R116 47K, R117 1K, R119 4K7 into 5B => summed).
  (MAME: trumpet level selected by bit 0 of port A.)
- ANAL6 (AY1 ch C): R48 10K + C42 0.1µ + R81 10K -> jumper (open = disabled;
  MAME "#1 Ch. C disabled, open jumper").
- Mix bus: RULLANTE R124 39K, CASSA R105 56K, BASSO R106 68K, PIANO R90 68K,
  TROMBA R96 4K7 + R97 150K/C40 -> sum node "1/2" -> power amp.
- 4B LS156 + R41 8K2, R42 5K6, R43 3K3, R44 1K5, R73 820R, R74 390R, R75 150R,
  R76 47R: binary-weighted attenuator controlled by IOA0..IOA2 (+IOA? pins 13/3/1/15) —
  master volume / attenuation for signal 5 per MAME TODO ("74LS156 attenuation").
- TDA1510 2B car-radio power amp (bridge): outputs SPK0/SPK1 (pins 6/9? via C10/C11
  100µF), R5/R6 4.7R zobels, R1/R2 100K, R9 2K2/C14 4.7µ feedback, C6 0.22µ.
- Power: +12 (D1 1N4004), +5, -5, VO gnd; C1 2200µ reservoir.

## Sheet 3/3 — speech/effects CPU

- Second 6802 ("audiocpu") top-left: XTAL1 pin39 = CKµ from SH1 (shared 3.58MHz osc).
  AR3/AR5 10K pullups. VMA1, R/W1, E1 out.
- Decode: 4E LS139 ×2 + 5E LS00/6H: VMA1+AD12/AD13 -> /CS1 /CS0 (module ROM selects
  9/13 via CNA), AD14 gate; AD10/AD11 -> /CSDIA (MC1408 DAC latch), /CSCOM (comm
  latches), /CSH (HS command buffer), /CSP (PIA/speech).
- 6821 PIA 1I ("pia_1i", /CSP): PA0..7 <-> SPEECH 1H D0..7 (TMS5200 data bus,
  pins 26/24/22/19/12/13/14 order per speech pinout), PB0/PB1 = speech /RS //WS?
  (pins 10/11 -> speech 28/27?), CA2 -> speech pin 18 (/RS?), CB1 <- speech /INT
  (pin 17), CA1 <- ...; IRQA/IRQB -> /IRQ (R29/R31/R28 3K3).
- SPEECH 1H = TMS5200-family ("SPEECH"): oscillator R19 100K/C24 22pF (RC, pin 3/2),
  SP output pin 8 -> R62 220K/C33 470p/R61 820K -> 4D 3900 mixer (R49 820K/C30 47p
  feedback, R50 820K bias) - mixes speech with DAC audio "a (SH2)" -> P2 10K pot ->
  C21 -> R18 10K -> E1-gated... -> to sheet2 mix ("2 (SH3)" node).
  ACS: 1A? LS14 4A pin13->12 from PIA (pin13?) -> ACS -> CN2-12 (audio-command-status
  read back by main CPU; MAME acs_r = bit 3 of COINS).
- MC1408 1F 8-bit DAC ("dac"): data from 2F LS374 (latched by /CSDIA from DIA0..7 =
  audiocpu D bus), output pin 4 -> R13 3M3/R12 3K3 -> T4 2N4401 (R14 3K3, R15/R16
  3K3/2K2, P3 10K pot, C20 0.01) -> node "a" -> speech mixer 4D. (PCM samples.)
- 2G LS374 (/CSCOM write): D0..7 -> IOB0..IOB7 — comm register readable by melody
  CPU AY2 port B (sheet 1). (Inter-CPU link, MAME zaccaria_a melody<->audio via
  8910 portB read.)
- 2E LS244 (/CSH read): HS0..7 (sound command S0..7 from I/O board via CN2 pins
  15/5/17/13(?)...) -> audiocpu D bus. /IRQ also pulled by command strobe? (CSH ->
  5E LS00 pair -> /IRQ set — MAME hs_w -> audiocpu IRQ.)
- T1 2N3904/T2 BC327/T3 BC327 + R20..R27 + LD1 LED + T5 2N3904 (R33 8K2, R32 470R):
  speech-active indicator + SP audio gating/mute.
- P1 pushbutton on 6802 /NMI (bottom left, "H P1"): the pinball-leftover test button
  noted in MAME TODO.
- CN2: 15..13 HS0..7 rows, 1/2 SPK0/SPK1?, no — CN2 right column: 1=SPK0? (schematic:
  SPK0/SPK1 arrive figure right: pins 1,2), +5/-5/+12 (10/9/5/3/4), 12=ACS,
  19=RESSOUND. (Cross-check with io digest CN3 map: 20=SPK1 19=SPK0 — module-side
  numbering differs; verify when wiring MRA.)

## MAME cross-check notes

- Structure matches zaccaria_a.cpp 1B11142: melody 6802 + PIA + 2×8910 (ch names
  match the Italian instrument labels in the MAME comment) and audio 6802 + PIA +
  TMS5200 + MC1408, netlist filters.
- Melody AY clocks in MAME: 3.579545/2 = 1.7898MHz (listxml says 1789772Hz)
  — schematic CKGI comes from 4040 5F: confirm it's /2 of XTAL (not /4).
  TMS5200 clock 649200Hz (RC osc R19/C24) per listxml.
- The comm path main->audio: S0..7 latch + /CSH read + IRQ, audio->main: ACS bit;
  melody<->audio: IOB latch. All three visible on the sheets.
