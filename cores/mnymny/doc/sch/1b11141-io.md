# 1B11141 Z80µP I/O (CPU) board digest

3 sheets, P82-003/B/M1, 17.5.83. Connectors: CN1 (50-pin to video board),
CN2 (edge: controls, RGB out, speaker, power), CN3 (to audio board: S0..S7,
HSOUND, RESSOUND, SPK, power), CN4 (to ROM module: /CS1../CS6, address, data).

## Sheet 1/3 — CPU, memory, decode

- Z80 at 4A. Clock φ: 1Hµ from video CN1-26, buffered/shaped by 2E LS367 (×3 stages,
  with pullup) -> pin 6. 1Hµ = 6.144MHz/2 = 3.072MHz (matches MAME 18.432/6).
- /WAIT (pin 24): 3D LS74 ×2 clocked by HBLANK(SH3)//SABBKG via 5C LS02 —
  holds the CPU off the tile RAM during active display (CPU only gets the bus in
  blanking; source of the "6000-67ff" access timing).
- /NMI (pin 17) <- /INT net from 3F LS74: set by /VBLANK (SH3), gated by INTST
  (LS259 output, MAME nmi_mask), cleared by /INTST low (3F /CLR). R2 4K7 pullup.
  (MAME: vblank_irq -> NMI when nmi_mask.) The Z80 /INT pin appears unused (pulled up).
- /RESET: 1D TL7705 supervisor (C1 0.1µ, R67 10K) + Q1/Q2 BC548/BC327 + D1/D2 1N4148,
  R14-R16 10K net, 5E LS04 buffers -> /RESET (SH2) and RESET (SH2, for 8255).
  Also 5C LS02 combines watchdog: 2F LS393 counter clocked by VBLANK, cleared by
  /RDSW (any DSW/service read resets the dog); overflow (pin12/13, ~128 frames?) -> reset.
- Program ROM on board: 1A "2732 or 2764" (CPU5-6 region? cs via 20/22 jumpers, /CS1),
  plus 1B = second ROM socket (CE/OE/WE pins shown with /CSRAMNV, /RDB, /WRB —
  1B is actually the NVRAM-mode socket? 1B pins 20 /CE 22 /OE 27 /WE with VCC pin28 —
  a 2816-style EEPROM option? Marked ambiguous — main map 8000-DFFF are module ROMs).
- Work RAM: 2A, 2B 2114 (1K×8 total) selected by /CSURAM1 — MAME 7000-77FF (2KB!) —
  wait: 7000-77FF is 2KB => two pairs; 2C, 2D are "2114 or 6514" (CMOS) on VBAT:
  battery-backed half (high-score NVRAM), /CSURAM2, write-protected by /W.D gate
  1C 74HC32 pair (a/b/c terms with /CSURAM2 and W.D).
- Battery: 3.6V NiCd + D28 1N4148 + R68 220R -> VBAT to 2C/2D and 4C EA gate.
- Address decode:
  - 3C LS138 (A12..A14 + /MREQ//RFSH via 5D LS00): /CS1../CS6 -> CN4 pins 30/35/43/34/36
    (ROM module selects, 0000-5FFF+8000-DFFF split via ROM_CONTINUE mapping) + /CSBB.
  - 4C LS139 half: AB10/AB11 (within /CSBB=6xxx-7xxx): /CSURAM1, /CSURAM2, /CS8255, /AFR;
    EA gated by VBAT-protection. Other half + 4E LS02: /CSRAMNV, /SABOBJ, /SABBKG
    (video RAM regions 6000-67FF bkg, 6840-68C0 obj).
  - 4D LS155 (A B = AB10 AB11, gates /RDB //WRB via 5E LS04): /WRBKGL /WRBKGH /WROBJ
    (writes) and /RDBKGL /RDBKGH /RDOBJ (reads) -> CN1 to video board.
  - 4F LS32 ×4: /WRMIX (write 6C00-6C07 -> LS259), /WRSOUND (6E00 write -> sound latch),
    /RDGETT (read handshake/GET), /RDSW (6E00 read DSW), from AB9 + /AFR terms + 5E.
- 3G LS259 ("mainlatch", addr AB0..2, D = DBB0, E = /WRMIX, /CLR = /RESET):
  Q0? -> HCMA (SH3) [flip], Q? -> RESSOUND (SH3), COUNT (SH2, coin counter Q3/Q4
  transistor driver on sheet 2), /INTST (Q7, NMI mask), VCMA (SH3) via 2E buffer.
  MAME order: Q0 VCMA(flipx) Q1 HCMA(flipy) Q2 RESSOUND Q6 COUNT Q7 INTST — pin-map TBC.
- Bus buffers: 4B + 3B LS244 address -> AB0..AB15 (to CN1/CN4), 2G LS245 data ->
  DBB0..7 (direction /RDB, enable /CSBB), 5D/5E misc gates, 4E LS02 SABBKG/SABOBJ ORs.
- CN4 (ROM module): AB0..AB11+A15 rows, D0..D7 (raw CPU data), /CS lines, /RDB /WRB /RFSH.
  Note D0..D7 to module are unbuffered CPU data; DBB3..7 also routed (protection PAL
  reads/drives high nibble via module — see 1b11147).

## Sheet 2/3 — inputs, DIP mux, sound latch

- 8255 4H (/CS8255 = 7800-7803): PA0..7 = player 1 stick+buttons (1JST L/R, 1P SHOOT1..4,
  1JST U/D), PB0..7 = player 2, PC0..3 inputs = 1 PLAYER, 2 PLAYER, SERVICE 1, SERVICE 2;
  PC4..6 outputs = DIP row select. All inputs RC-filtered (20×1K + 20×220R + 20×0.1µ).
- DIP switches: 3 banks × 8 (5I, 4I, 3I per DIP table page) wired as a diode matrix
  (24× 1N4148) scanned by PC4/PC5/PC6; readback through 40097 hex buffers 3H + 2I
  (two groups) onto DBB0..7 when /RDSW (dsw_r at 6E00; MAME dsw_sel_w values 8H/9H/BH
  select rows -> PC bits). GET1..3 (CN2 B13/A14/B14, extra coin/gettone inputs) read
  through the second 40097 group with 3×1K/220R/0.1µ filters (RDGETT).
- Sound command: 2H LS374 latched by /WRSOUND -> S0..S7 to CN3 (audio board HS0..7).
  /OE tied low... /OE = gnd via pin1. HSOUND (CN3-9, handshake from audio board)
  read via /RDGETT path (MAME acs_r bit in COINS port).
- Coin counter: COUNT (SH1) -> R17 4K7 -> Q3 BC548 -> Q4 BC337 + D3 1N4004 ->
  CN2 A13/A15 (counter coil).
- Video pass-through to cabinet: R,G,B,/SYNC from CN1 -> CN2 (B2/A1/B1/A2); SPK0/SPK1
  from CN3 -> CN2 (A21/A22); power: +12 (B21/B22), +5 (A16..A18), -5 (B16..B18 VBB),
  ground B15.

## Sheet 3/3 — connector maps

- CN1: same 50-pin map as video digest (DBB, AB0..9, RGB+/SYNC in, 1Hµ, blanks,
  /SABBKG /SABOBJ, VRAM strobes, HCMA/VCMA).
- CN3 (audio): 6=S0 3=S1 4=S2 1=S3 10=S4 7=S5 5=S6 8=S7, 9=HSOUND, 2=RESSOUND,
  18/17=+12VDD, 16/15=-5VBB, 12/11=+5VCC, 20=SPK1 19=SPK0, 14/13=GND.

## MAME cross-check notes

- Memory map fully consistent with MAME main_map (0000-5FFF ROM, 6000-67FF bkg VRAM
  4-bit-high section, 6400-6407 prot1 on D4..7, 6800-683F attributes, 6840-685F/6881-68C0
  obj RAM, 6C00-6C07 prot2+LS259 mirror 0x81F8, 6E00 dsw/sound mirror, 7000-77FF RAM,
  7800-7803 8255, 7C00 watchdog, 8000-DFFF ROM).
- Watchdog: MAME uses watchdog reset_r at 7C00 read; schematic clears the LS393 with
  /RDSW — check which strobe really reaches it (7C00 vs 6E00 decode) when transcribing
  pin-level. (4F gate inputs worth a re-zoom.)
- NMI gating INTST matches nmi_mask_w bit7 of LS259.
