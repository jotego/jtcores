# Wardner

Toaplan TP-009 / Taito B25 (1987): Wardner, Wardner no Mori, Pyros.

- Z80 at 6 MHz with banked ROM
- TMS320C10 at 14 MHz, which halts the Z80 and works in its RAM
- Z80 and YM3812 at 3.5 MHz, sharing 2 kB of RAM with the main CPU
- three tile maps and 512 sprites, 320x240 at 54.878 Hz

`doc/` holds the MAME 0.289 sources the core follows.
