# Pocket check list

Available games
- No JSON files for games that don't work
- If a game does not work on the Pocket, but works on
  Mist, make a GitHub issue in the JT project repository

Performance
- Video is stable (does not go blank when it shouldn't)
- Audio is correct, with no hissing noise
- Video layers are shown correctly
- Sprites are shown correctly
- Play one full level

Settings
- Default button mapping makes sense for the game
- Default screen orientation is correct (check flip setting)
- DIP switches have the expected effect
- Check NVRAM operation (if the core has NVRAM)

OSD screen
- JT logo is centered and only displayed once
- Chip ID is visible in the pause screen

Vertical games
- Screen orientation matches the menu
- Flip option either works or is disabled
- Input rotation works
