# Actual-ascal frame capture simulation

`sim.sh` snapshots the exact production `ascal.vhd`, adversarial Avalon memory model, and testbench into its output directory, records their SHA-256 hashes, then compiles only those frozen copies with GHDL 2008 (tested with GHDL 4.1). It runs the progressive 24-bit raster with `CAPTURE=false/true` and two arbitrary row-padding fills (`00` and `A5`), plus focused capture backpressure, write-ID wrap/coalesced-ACK, and write-collision recovery cases.

The ordinary-image baseline checks actual scaler writes, Avalon burst stability/completion, read traffic, and every visible RGB byte in all three input slots. It independently identifies the source frame from the first pixel and checks that every pixel in every row has the same frame ID, expected coordinates and RGB byte order. The raster is 87×9 pixels, so each row has 261 visible bytes in a 512-byte pitch and crosses both a 16-byte word and 256-byte burst boundary. The test substitutes arbitrary values only for unknown bits in actual row padding; it preserves known bits, audits accepted physical addresses, and compares `00` versus `A5` fills. Visible RGB, header words and all nonpadding writes remain strict. It also checks nine ordinary legacy header counters across modulo-8 wrap. The model has a compact 64 KiB footprint per slot while retaining the real 2 MiB physical slot stride.

The capture target tests use actual source-raster LVBL falling edges and an independent frame manifest. The selected slot is checked against all visible RGB bytes while READY, then the test checks clean release and resumed video. The actual descriptor carries a sequential IEEE CRC and is validated against an independent reference. The completion scan must return every target pixel burst before the deterministic metadata/header fence can publish READY. A two-result run delays the first result-cache ACK: the premature re-arm is rejected without overwriting the retained result, then the acknowledged retry produces a fresh second READY result. A fault path verifies that the published descriptor remains unchanged through wrong-release cleanup. A shared-reset case holds READY without result ACK, asserts the common reset, and verifies that state, result bytes, and result toggle clear together. A watchdog run stops `i_clk`, verifies that the Avalon→CAP_IO fault mailbox invalidates stale READY, resumes `i_clk` for cleanup and re-arms from sticky fault. Write-order tokens are local 8-bit modulo-256 values; descriptor `final_issued` and `final_completed` are each the zero-extended token from their respective issue and ordered-ACK streams (zero is valid), not monotonic lifetime write counts. The Avalon drain and controller ACK stream must both reach the inclusive final ID before READY metadata can be emitted. The final-beat stall test holds a target write after issue but before ordered completion and verifies that no READY/result is published; after release, the descriptor reports the completed token and its CRC validates. A separate run crosses the `FF`→`00` wrap with coalesced half ACKs. Other directed cases stall the first beat of each leased half while its reuse is attempted. The runner also checks that an unsupported ARM does not stop ordinary progressive video, and that an unsupported-mode fault after ARM returns the held scaler to IDLE on watchdog expiry while preserving its first fault. Interlaced capture remains unavailable in the initial wrapper qualification.

These simulations prove the bounded synthetic ascal behavior only. They do not establish full JTFRAME CAB-to-ascal start lifecycle phase, wrapper/build integration, physical HPS mapping attributes, supported rotated/framebuffer modes, release cadence on hardware, resource/timing margin, or repeatability on the MiSTer devices. Interlaced capture remains unsupported and must be advertised unavailable by the wrapper.

Run from any directory:

```sh
./sim.sh [output-directory]
```

GHDL output and frozen source hashes are retained under the requested or generated output directory. The model's independent self-test is at `/nobackup/tasks/jtcores-224/artifacts/review/avalon-model/run.sh`.
