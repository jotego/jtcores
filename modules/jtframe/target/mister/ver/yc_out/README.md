# `yc_out` regression

Run `./sim.sh` from this folder. The standalone Verilator bench instantiates PAL
Y/C, NTSC Y/C, PAL CVBS and NTSC CVBS outputs. It checks all 256 signed LUT
entries against the baseline table and compares every observable chroma/CVBS
sample against a separate fixed-point reference generated by `reference.py`.
The trace covers sync/DE timing, both PAL line phases, burst boundaries,
blanking with red input, and RGB/gray transitions. A per-cycle luma scoreboard
checks active DE gating and alignment independently.

Set `YC_EVIDENCE_DIR` to copy the compact sampled CSV and input/reference hex
vectors there before the runner cleans its generated files. The normal test
emits only its PASS summary.
